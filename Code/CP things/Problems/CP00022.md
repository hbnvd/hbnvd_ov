# 01. by hbnvd - O(n\*k) - O(n\*k)
## Idea
- Gọi $f(i,j)$ là hàm tính số cách chọn sách với $i$ kệ và còn $k$ lần chọn
- nếu chọn bốc ở kệ sách $i$ có $A_i$ quyển thì ta có $A_i$ trường hợp
- bruh nó là công thức toán học bình thường thôi;)

## Cpp
%% Code chỉ ghi biến cần thiết ,core, không ghi full %%
```cpp
int n, k;
ll a[1005];
ll mem[1005][1005];
memset(mem, -1, sizeof(mem));
// input ..

ll dp(int i, int j) {
    if (j == 0) return 1LL;
    if (i == 0) return 0LL;
    if (mem[i][j] != -1) return mem[i][j];
    

    ll res = dp(i-1, j); // not choose
    res = (res + (dp(i-1, j-1) * (a[i]%oo))) % oo; // choose

    return mem[i][j] = res;
}

cout << dp(n, k) << "\n"; 
```
# 02. by hbvnd - O(n\*k) - O(n\*k)
## Idea
- Như trên nhưng bottom up
## Cpp
```cpp
int n, k;
int a[1005];
ll dp[1005][1005];
// input...

// for (int i = 1; i <= n; ++i) {
//     dp[i][0] = 1;
// }
dp[0][0] = 1; // dp[0][0] sẽ tự lan ra nên không cần vòng for trên

for (int i = 1; i <= n; ++i) {
	for (int j = 0; j <= k; ++j) {
		dp[i][j] = dp[i-1][j];
		if (j > 0) {
			dp[i][j] = (dp[i][j] + ((dp[i-1][j-1] * a[i])%oo))%oo;
		}
	}
}
cout << dp[n][k] << "\n";

```
