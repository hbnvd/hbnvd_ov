# 01. usr hbnvd - O(n^2) - O(1)
- Brute Force
## Idea
- Ta xét ở từng cột nước riêng lẻ, ở cột thứ $A_i$  chiều ngang ($wid$) luôn là 1, độ cao ($hei$) sẽ là $\min(\text{Cột cao nhất bên trái, cột cao nhất bên phải}) - A_i$
- Khi này chỉ cần duyệt qua từng $A_i$ rồi tìm cột cao nhất bên trái, cột cao nhất bên phải rồi cộng dồn vào 1 biến tích lũy.
## Cpp
```cpp
int n;
int a[100005];

cin >> n;
for (int i = 1; i <= n; ++i) {
	cin >> a[i];
}
if (n <= 2) {
	cout << 0;
	return 0;
}

// CORE
int ans = 0;
for (int i = 2; i <= n-1; ++i) {
	int mx_l = a[i], mx_r = a[i];

	for (int j = 1; j <= i-1; ++j) {
		mx_l = max(mx_l, a[j]);
	}
	for (int j = i+1; j <= n; ++j) {
		mx_r = max(mx_r, a[j]);
	}
	
	ans += min(mx_l, mx_r) - a[i];
}
cout << ans << "\n";


```
# 02. usr hbnvd - O(n) - O(n)
## Idea
- Tương tự [[#01. usr hbnvd - O(n 2) - O(1)]] nhưng ta có thể thay thế việc truy vấn max (ở line 34 ~ 39) bằng prefix / suffix max.
## Cpp
```cpp
// INIT
int n, m;
int a[100005];
int prf[100005];
int suf[100005];

cin >> n;

for (int i = 1; i <= n; ++i) {
	cin >> a[i];
}
if (n <= 2) {
	cout << 0;
	return 0;
}
// Tạo prf, suf sum
prf[1] = a[1];
for (int i = 2; i <= n; ++i) {
	prf[i] = max(prf[i-1], a[i]);
}
suf[n] = a[n];
for (int i = n-1; i >= 1; --i) {
	suf[i] = max(suf[i+1], a[i]);
}

// CORE
int ans = 0;
for (int i = 1; i <= n; ++i) {
	ans += min(prf[i], suf[i]) - a[i];
}
cout << ans << "\n";
```

# 03. usr hbnvd - O(n) - O(1)
## Idea

- Cho 2 con trỏ $l,r$ , và biến $water$ đại diện cho tổng lượng nước trong thùng
- Cho 2 biến $mxl$ (giá trị lớn nhất bên trái $l$), $mxr$ (giá trị lớn nhất bên trái $r$), đây chính là "vách ngăn" của thùng nước mà ta cần dùng để tính.
- Lấy câu nói rất "chuyên gia" ở  phía trên mục [[#01. usr hbnvd - O(n 2) - O(1)]] 1 line, ta sẽ ưu tiên tính lượng nước ở con trỏ có "vách ngăn" thấp hơn con trỏ còn lại.

## Cpp
```cpp
// INIT
int n, m;
int a[100005];
int prf[100005];
int suf[100005];

cin >> n;
for (int i = 1; i <= n; ++i) {
	cin >> a[i];
}
if (n <= 2) {
	cout << "0\n"; continue;
}

// CORE
int l = 2, r = n-1; // tường sát biên không thể chứa nước
int mxl = a[1], mxr = a[n];
int water = 0;

while (l <= r) {
	if (mxl < mxr) {
		water += max(0, mxl - a[l]); // Trường hợp đụng vách ngăn mới
		mxl = max(mxl, a[l]); // vừa đi vừa tính vách ngăn mới;)
		++l;
	} else {
		water += max(0, mxr - a[r]); // như trên nhưng là cho mxr
		mxr = max(mxr, a[r]);
		--r;
	}
}

cout << water << "\n";
```
# 04. usr hbnvd - O(n) - O(n)

## Idea
- Khi ở trong vòng while, bạn có thể hình dung là 
	- Phần tử trong stk được pop: sàn
	- a\[i] : **vách phải**
	- stk.top() sau khi pop: **vách trái**
- Nếu có stk.top() sau khi pop cũng là sàn thì water sẽ ra 0, while sẽ chạy tiếp cho tới khi tìm được vách trái hợp lí.

- Test case nên thử suy ngẫm
```txt
4 0 0 1 0 0 5
```

## Cpp
```cpp
int n;
int a[100005];
// input ...


// CORE
int total_water = 0;
stack<int> stk;
for (int i = 0; i < n; ++i) {
	while (!stk.empty() && a[stk.top()] < a[i]) {
		int pop_hei = a[stk.top()]; // also cool
		stk.pop();
		
		if (stk.empty()) {
			break;
		}
		
		int distance = i - stk.top() - 1;
		int water = min(a[i], a[stk.top()]) - pop_hei; // really cool
		
		total_water += water * distance;
	}
	stk.push(i);
}

cout << total_water << "\n";

```
