# 01. by hbnvd - O(n^2) - O(n)
## Idea
- Ở cột thứ $i$ ta thử từng diện tích với những cột bên trái.
- Khi dùng $j$ để tính diện tích từ $i$ xuống 0, chỉ những cột thấp hơn cột đã được tính trước đó (trong phạm vi $[i,j]$) mới có thể tính tiếp.
## Cpp
%% Code chỉ ghi biến cần thiết ,core, không ghi full %%
```cpp
// input...


int ans = 0;
for (int i = 0; i < n; ++i) {
	int min_hei = a[i];
	
	for (int j = i; j >= 0; --j) {
		min_hei = min(min_hei, a[j]);
		ans = max(ans, min_hei*(i-j+1));
	}
}
cout << ans << "\n";
```
# 02. by hbnvd - O(n^2) - O(n)
## Idea
- Nhận xét: ở cột thứ $i$ ta chỉ cần xét những phần tử bên trái nhỏ hơn $A_i$ và cách phần tử đó mang tính đơn điệu , tạm gọi tập chứa địa chỉ trong $A$ của các phần tử đó là $V$, 1 $V_x$ chỉ có thể trỏ tới 1 $A_i$
- Khi xét phần tử trong tập $V$, diện tích của nó trong phạm vi $i,j$ là:$$ans = \max(ans\space, A_{V_j}(i-V_{x-1}))$$
- Với tính chất `nhỏ hơn A_i` và `mang tính đơn điệu`, ta có thể áp dụng monotonic stack, nhung vì cần truy cập lại từng phần tử trong $V$ mỗi lần cập nhật $i$ nên ta sẽ dùng vector (vẫn có back(), pop()).  
- Vì trong công thức ta có tính chiều rộng của hình chữ nhật hiện tại và lấy biên trái là phần tử nhỏ hơn gần nhất bên trái, nên ta phải thêm 0 vào đầu mảng để phòng trường hợp tính diện tích ở biên trái.
## Cpp
```cpp
a.insert(a.begin(), 0); // thêm 0 vào đầu mảng
vector<int> vt = {0}; // thêm luôn địa chỉ của a[0] vào đầu vt

int ans = 0;
for (int i = 1; i <= n; ++i) {
	// monotonic stack bình thường
	while (!vt.empty() && a[vt.back()] >= a[i]) {
		vt.pop_back();
	}
	vt.push_back(i);

	for (int j = 1; j < (int)vt.size(); ++j) {
		ans = max(ans, a[vt[j]]*(i-vt[j-1]));
	}

}
cout << ans << "\n";

```
- Nhận xét: bài này vẫn là O(n\^2), nhưng sẽ nhanh hơn do không duyệt lại những phần tử lớn hơn hoặc bằng $A_i$
# 03. by hbvnd - O(n) - O(n)
## Idea
- Lười vl, đọc thử [[CP00011#04. usr hbnvd - O(n) - O(n)]] đi, y chang nhau á;)), nhưng mà bài này phải thêm 0 vào đầu và cuối cho trường hợp biên.


## Cpp
```cpp
// input..

a.insert(a.begin(), 0);
a.push_back(0); // 2 cái này cho trường hợp biên, tự suy nghĩ đi;)

stack<int> st;
int ans = 0;

// CORE
for (int i = 0; i <= n+1; ++i) {
	while (!st.empty() && a[st.top()] > a[i]) {
		int hei = a[st.top()];
		st.pop();

		int wid = i-st.top()-1;
		ans = max(ans, hei*wid);
	}
	st.push(i);
}
return ans;
```
