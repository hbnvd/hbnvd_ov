# 01. by hbnvd - O(n^2) - O(n)
## Idea
- Dùng prf sum duyệt qua mọi tổng rồi thử (thật ra không cần prf sum đâu nhưn tôi lười setup;)

## Cpp
%% Code chỉ ghi biến cần thiết ,core, không ghi full %%
```cpp
// input , set up prf sum các thứ


ll cnt = 0;
for (int r = 1; r <= n; ++r) {
	for (int l = 1; l <= r; ++l) {
		if (((prf[r] - prf[l-1])%n + n)%n == 0) {
			++cnt;
		}
	}
}

cout << cnt << "\n";
```


# 02. by hbnvd - O(n) - O(n)
## Idea
- Khi dùng tới định lý toán học (đồng dư modulo \<gắn tagggg\> ) ta thấy rằng
$$ \begin{aligned}
(prf_r - prf_{l-1}) &\equiv 0 \pmod{m} \\
prf_r &\equiv prf_{l-1} \pmod{m}
\end{aligned} $$
- Khi đó, với mỗi $prf_i$ ta có thể dùng map để lưu, tìm được số lượng $(prf_i)\mod m$ sau đó tính được số cặp có thể.

## Cpp
```cpp

int n; cin >> n;
ll cnt = 0;
ll prf = 0, a;


// CORE
// Vì prf[i], a[i] chỉ xài trong đúng 1 vòng lặp nên toi chỉnh thành biến O(1) lun:p
// vì 1 <= (prf[i]%m +m)%m < n nên ta có thể dùng mảng thay umap cho nhanh
int mp[10005]

int m = 0;
cnt += mp[m];
++mp[m];
for (int i = 1; i <= n; ++i) {
	cin >> a;
	prf = prf + a;
	
	m = (prf%n + n) % n;
	cnt += mp[m]; // với mỗi 1 m thì có mp[m] cặp có thể sinh ra dãy con
	++mp[m];
}
cout << cnt << "\n";

```
