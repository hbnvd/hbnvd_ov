# 01. usr hbnvd - O(n) - O(n)
## Idea
- Tạo mảng $prf = S(0, A)$ . Giả sử với `r cố định`, ta cần tìm $l<r$ sao cho $a.sum(l, r)$ là lớn nhất. Khi đó:
$$ \begin{aligned}
ans_r &= \max_{1 \le l \le r} (pref_r - pref_l) \\
&= pref_r + \max_{1 \le l \le r} (-pref_l) \\
&= pref_r - \min_{1 \le l \le r} pref_l \space\space\space\space(1)
\end{aligned} $$
- Nếu ta tạo 1 mảng $mn$ sao cho: $$mn_i=\min_{1 \le j \le i}prf_j$$ 
 - Thì ta có thể tính $ans_r$ với $O(1)$. Đáp án của bài toán là $ans =\max ans_r$ với $1 \le r \le n$. Khi này độ phức tạp tổng thể của bài toán chỉ là $O(n)$ thay vì $O(n^2)$.

## Step by step
1. Nhập: $A$
2. Tạo: $prf=S(0, A)$
3. Tạo: $mn$
4. Tiến hành tìm $\max ans_r$ dựa trên công thức $(1)$

%% Các bước 1, 2, 3, 4 có thể tiến hành trên cùng 1 vòng for %%

## CPP

```cpp

int n;
ll a[100005];
ll prf[100005], mn[100005];
// input ...

// khởi tạo prf sum, min
prf[0] = 0;
mn[0] = 0;
for (int i = 1; i <= n; ++i) {
	prf[i] = prf[i-1] + a[i];
	mn[i] = min(mn[i-1], prf[i]);
}
// CORE
ll ans = -2e18;
for (int i = 1; i <= n; ++i) {
	ans = max(ans, prf[i] - mn[i]);
}
cout << ans << "\n";
```
- Nên thử gộp các bước 1, 2, 3, 4 vào cùng 1 for trước khi đọc nhận xét
- Nhận xét thấy ta chỉ truy cập mỗi một $mn[i]$ và $prf[i]$ đúng 2 lần, nên ta có thể thay thế mỗi mảng thành 1 biến . %% Tự làm đi toi lười vl;)) %%
- Nhận xét thêm nữa là nếu làm như trên ta chỉ truy cập $a[i]$ đúng 1 lần thôi nên là...
- Bạn làm xong đống nhận xét trên thì chúc mừng, code của bạn tiến tới độ phức tạp không gian O(1) cmnr;))

# 02. usr hbnvd - O(n) - O(1)
## Idea
- Đi hỏi Kadane's ấy;)
## Cpp
```cpp

int n;
int a[100005];
// input ...


// CORE
int ans = a[1], sum = a[1];
for (int i = 2; i <= n; ++i) {
	sum = max(sum + a[i], a[i]); // đi tiếp or bắt đầu lại
	ans = max(ans, sum);
}

cout << ans << "\n";


```
