- **Khái niệm** của fibonacci có thể hiểu qua 2 dạng
1. Tiếp cận Top-down (Từ $n$ xuống dưới)
Phương pháp này đi từ bài toán lớn $F(n)$, phân rã thành các bài toán con nhỏ hơn cho đến khi chạm bài toán cơ sở (Base case).

$$
F(n) = 
\begin{cases}
0 & \text{nếu } n = 0 \\
1 & \text{nếu } n = 1 \\
F(n-1) + F(n-2) & \text{nếu } n > 1
\end{cases} \tag{Top-down}
$$

---

 2. Tiếp cận Bottom-up (Từ dưới lên trên)
Phương pháp này xuất phát từ các bài toán cơ sở đã biết trước là $F(0)$ và $F(1)$, sau đó dùng vòng lặp để tích lũy và tính dần lên các bài toán lớn hơn cho tới khi đạt được $F(n)$.

$$
\begin{aligned}
&\text{Khởi tạo: } &&F[0] = 0, \quad F[1] = 1 \\
&\text{Công thức tích lũy: } &&F[i] = F[i-1] + F[i-2] \quad \text{với } 2 \le i \le n
\end{aligned} \tag{Bottom-up}
$$

# 01. by hbnvd - O(2^n) - O(n)
## Idea
- dựa trên cách 1 trong phần khái niệm ở trên, áp dụng đệ quy
## Cpp
```cpp
#define ll long long


ll fib(int n) {
	if (n == 0) return 0;
	if (n == 1) return 1;
	return fib(n-1) + fib(n-2);
}

cout << fib(n) << "\n";
```

# 02. by hbnvd - O(n) - O(n)
## Idea
- áp dụng các 2 trong phần khái niệm

## Cpp
```cpp
#define ll long long

ll f, f1 = 1, f2 = 0;
for (int i = 1; i <= n; ++i) {
	f = f1 + f2;
	f2 = f1;
	f1 = f;
}
cout << f << "\n";
```
