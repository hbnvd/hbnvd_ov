# 01. usr hbnvd - O(n^2) - O(n)
## Idea
- 2 vòng for, duyệt mọi kích thức cửa sổ + duyệt mọi i
- Dùng prf sum để tính nhanh tổng của 1 cửa sổ.
## Cpp
```cpp
// Init
int a[100005], prf[100005];
int n, u, v; cin >> n >> u >> v;
// input ...


// CORE, duyệt mọi i, mọi kích thước cửa sổ
ll max_sum = -2e18;
for (int d = u; d <= v; ++d) {
	for (int i = 0; i <= n-d; ++i) {
		max_sum = max(max_sum, prf[i+d] - prf[i]);
	}
}
cout << max_sum << "\n";
```
# 02. usr hbnvd - O(n) - O(n)
## Idea
- Như bài [[CP00005#01. usr hbnvd - O(n) - O(n)#Idea]] đã chứng minh, giờ ta chỉ cần giải quyết việc tối ưu truy vấn $\min(prf_l)$, vì min cần tìm không nằm trong đoạn $1 \le l \le r$ mà trong  đoạn $r-v\le l \le r-u$ , ta không  thể dùng mảng min nữa mà phải chuyển sang [[Monotonic queue, stack#3. Hàng đợi đơn điệu (Monotonic Queue)|Monotonic queue]].

## Step by step
1. Tạo prf, ans, deque\<int\> dq;
2. Duyệt qua mọi r
	1. Trong vòng while ta sẽ cập nhật dq theo i-u và loại bỏ theo i-v
	2. So sánh với anse
## Cpp
```cpp
for (int i = u; i <= n; i++) {
	// setting monotonic queue
	while (!dq.empty() && prf[dq.back()] >= prf[i-u]) // thêm trong phạm vi i-u
		dq.pop_back();
	dq.push_back(i-u);
	while (dq.front() < i - v) // loại phần tử cũ quá phạm vi i-v
		dq.pop_front();

	ans = max(ans, prf[i] - prf[dq.front()]);
}
cout << ans << "\n";
```

# 03. usr hbnvd - O(nlogn) - O(nlogn)
## Idea
%% Cách này thêm vô cho zui:p %%
- Thì như cách trên, cũng dùng prf sum, cố định i, tìm min(prf\[i-u], prf\[i-v]), nhưng ta sẽ thực hiện truy vấn min với bảng thưa.

## Cpp
```cpp
// Init, input
int n, u, v; cin >> n >> u >> v;
prf[0] = 0;
sp[0][0] = 0;
for (int i = 1; i <= n; ++i) {
	cin >> a[i];
	prf[i] = prf[i-1] + a[i];
	sp[0][i] = prf[i];
}

// setting sp table
for (int i = 1; i < LOG; ++i) {
	// khúc này j=0 vì có thể gọi tới prf[0]
	for (int j = 0; j <= n - (1<<i) + 1; ++j) {
		sp[i][j] = min(sp[i-1][j], sp[i-1][j + (1<<(i-1))]);
	}
}


ll ans = -2e18;
// CORE
for (int i = u; i <= n; ++i) {
	int l = max(0, i-v), r = i-u;
	int k = __lg(r-l+1);
	// thay dq với công thức truy vấn của bảng thưa
	ans = max(ans, prf[i] - min(sp[k][l], sp[k][r - (1<<k) + 1]));
}
cout << ans << "\n";

```
