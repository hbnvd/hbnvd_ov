# 01. by hbnvd - O(n) - O(n)
## Idea
- Gọi $f(i)$ là thời gian nhỏ nhất $i$ người cần để mua vé
- Ở trạng thái $f(i)$ ta có thể chọn mua vé cho bản thân hoặc mua vé cùng người thứ $i-1$ 
$$f(i)=\min(f(i-1)+T_i,f(i-2)+R_{i-1})$$
## Cpp
```cpp
int n;
int t[100005], r[100005];
memset(mem, -1, sizeof(mem))
// input...

int dp(int i) {
    if (i <= 0) {
        return 0;
    }
    if (i == 1) {
        return t[i];
    }
    if (mem[i] != -1) {
        return mem[i];
    }
    return mem[i] = min(dp(i-1) + t[i], dp(i-2) + r[i-1]);
}

cout << dp(n) << "\n";
```

# 02. by hbnvd - O(n) - O(n)
## Idea
- Như trên nhưng xây từ dưới lên, và nhanh hơn do không cần tốn chi phí gọi hàm
## Cpp
```cpp
int n;
int t[100005], r[100005];
int dp[100005];
// input ...


dp[1] = t[1];
for (int i = 2; i <= n; ++i) {
	dp[i] = min(dp[i-1] + t[i], dp[i-2] + r[i-1]);
}
cout << dp[n] << "\n";

```
