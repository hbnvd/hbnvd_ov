# 01. usr hbnvd - diff arr & prf sum- O(n) - O(n)
## Idea
[[Prefix Sum & Different Array#III. Ứng dụng#Difference Array]]

## Step by step
1. Tạo: $dif$ với $N$ số $0$
2. Chạy qua $Q$ truy vấn, với mỗi truy vấn $l, r$, -> ++dif\[l], --dif\[r+1]
3. Tạo: $prf=S(0, dif)$, đồng thời $prf$ cũng chính là $A$ mà ta cần cập nhật

# CPP
```cpp
#include <bits/stdc++.h>
using namespace std;

void fileIO() {
    #ifdef LOCAL_DEBUG
        freopen("testcpp1.INP", "r", stdin);
        freopen("testcpp1.OUT", "w", stdout);
    #endif
}

#define ll long long

int n, q;
int dif[100005];
int prf[100005];
int main() {
    fileIO();
    
    cin >> n >> q;
    int l, r;
    while (q--) {
        cin >> l >> r;
        ++dif[l];
        --dif[r+1];
    }
    prf[0] = 0;
    for (int i = 1; i <= n; ++i) {
        prf[i] = prf[i-1] + dif[i];
        cout << prf[i] << " ";
    }
    cout << "\n";
    return 0;

}

```
- Nhận xét thấy ta chỉ duyệt một $prf[i]$ đúng 2 lần khi duyệt chính $prf[i]$ và $prf[i-1]$ ở vòng lặp sau nên có thể bỏ $prf$ và thay bằng 1 biến cũng được nhưng toi lười vl nên NO:)
