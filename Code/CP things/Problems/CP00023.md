# 01. really by hbnvd - O(n^2) - O(n^2)
## Idea
- Gọi $f(i, j)$ là hàm tính độ dài dãy con tăng dài nhất trong đoạn $[1, i]$, có vị trí cuối của dãy là $j$
$$f(i,j)=f(i-1,j)$$
$$f(i, i) = \max \Big( f(i, i), \, f(i, j) + 1 \Big) \quad \text{nếu } A_i > A_j$$

## Cpp
```cpp
int n;
int a[1005];
int dp[1005][1005];
// input ...

for (int i = 1; i <= n; ++i) {
	dp[i][i] = 1;
	for (int j = 1; j < i; ++j) {
		dp[i][j] = dp[i-1][j];
		if (a[i] > a[j]) {
			dp[i][i] = max(dp[i][i], dp[i][j] + 1);
		}
	}
}

int ans = -1e9;
// dãy con tăng dài nhất có thể kết thúc với mọi j
for (int j = 1; j <= n; ++j) {
	ans = max(ans, dp[n][j]);
}
cout << ans << "\n";
```
# 02. by hbnvd - O(n^2) - O(n)
## Idea
- Ở cách 1, ta nhận thấy chỉ cần sử dụng giá trị "kết thúc tại j", chứ không cần "nằm trong đoạn i", nên sẽ sửa lại:
- Gọi $f(i)$ là độ dài dãy con tăng dài nhất kế thúc ở $i$
$$f(i) = \max_{1 \le j \le i}(f(j)) \quad(\text{nếu  }A_i>A_j)$$
## Cpp
```cpp
int n;
int a[1005];
int mem[1005];
memset(mem, -1, sizeof(mem));

int dp(int i) {
    if (i <= 0) return 0;
    if (mem[i] != -1) return mem[i];
    
    int res = 0;
    for (int j = 1; j < i; ++j) {
        if (a[j] < a[i]) {
            res = max(res, dp(j));
        }
    }
    return mem[i] = res + 1;
}


int ans = -1e9;
for (int i = 1; i <= n; ++i) {
	ans = max(ans, dp(i));
}
cout << ans << "\n";
```
