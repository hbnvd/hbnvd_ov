# 01.  by hbnvd - O(26\*n^2) - O(n)
## Idea
- Duyệt từ A tới Z, thử tửng độ dài.

## Cpp
```cpp
string s; cin >> s;
int k; cin >> k;

// lc
int n = (int)s.length();
int ans = 0;
// input ..

// CORE
// Thử từ A tới Z, xem c là kí tự chính, không thể bị thay thế
for (int c = 'A'; c <= 'Z'; ++c) {
	for (int i = 0; i < n; ++i) {
		int rep = 0;
		
		for (int j = i; j < n; ++j) {
			if (s[j] != c) ++rep;
			
			if (rep <= k) {
				ans = max(ans, j - i + 1);
			} else {
				break;
			}
		}
	}
}
return ans;
```

# 02. by bhvnd - O(26\*n) - O(n)
## Idea
- Cũng thử từ A tới Z, nhưng ở đây ta sẽ sliding window
- Cụ thể là liên tục tăng $r$. Chỉ tăng $l$ khi $rep$ (lưu số lượng kí tự sẽ bị thay thế) lớn hơn k.

## Step by Step
%% Idea nhưng chi tiết, từng bước %%

## Cpp
%% Code chỉ ghi biến cần thiết ,core, không ghi full %%
```cpp

string s; cin >> s;
int k; cin >> k;

// lc

int n = (int)s.length();
// input ...

int ans = 0;
// CORE
for (char c = 'A'; c <= 'Z'; ++c) {
	int rep = 0; // replace upper case char
	for (int l = 0, r = 0; r < n; ++r) {
		if (s[r] != c) {
			++rep;
		}
		while (rep > k && l < r) {
			if (s[l] != c) {
				--rep;
			}
			++l;
		}
		ans = max(ans, r-l+1);
	}
}
// lc
cout << ans << "\n"; // return ans;
return;

```
# 03. by hbnvd - O(n) - O(n)
## Idea
%% Cái này ms peak này:) %%
- Cửa sổ không bao giờ thu lại (++l), chỉ mở rộng (++r) hoặc tịnh tiến (++l, ++r)
- Vì để tìm được $ans$ tốt hơn $ans$ hiện tại thì cửa sổ phải lớn hơn chứ không thể nhỏ hơn.
- Vì size window là $ans$ và nó luôn ở kích cỡ best (kể cả khi về sát biên $n$) nên  ta chỉ xét ans khi $r$ chạy hết vòng lặp với công thức sau: $ans = r-l+1=n-l$

- Còn về tầng suất của kí tự xuất hiện nhiều nhất thì ta lấy $max_f = \max(max_f, frq[s[r]])$, frq là mảng lưu tần suất của tất cả kí tự trong phạm vi cửa sổ.
## Cpp
```cpp
string s; int k; cin >> s >> k;
int n = (int)s.length();
// input...

// CORE
int frq[105] // tần suất
int l = 0; // bắt buộc l phải cùng scope với main
int mx_f = 0, ans = 0;

for (int r = 0; r < n; ++r) {
	++frq[s[r]];
	mx_f = max(mx_f, frq[s[r]]);

	if ((r-l+1) - mx_f > k) {
		--frq[s[l]];
		++l;
	}
}
ans = n-l; cout << ans << "\n";

return;
```
