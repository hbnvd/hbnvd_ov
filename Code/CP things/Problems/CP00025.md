# 01. by hbnvd - O(n) - O(n)
## Idea
- Gọi $f(i)$ là hàm tính số cách sơn hàng rào với $i$ tấm ván
- 2 cách sơn hàng rào được coi là khác nhau nếu  tất cả ô màu cam trên 2 hàng rào không cùng số lượng hoặc không có cùng vị trí.

- ở vị trí $i$ ta có hai lựa chọn:
	- Sơn màu vàng: nối tiếp số cách sơn từ trạng thái $f(i-1)$
	- Sơn cam: để sơn ở $i$ thì ván ở $i-k$ phải là ván cam gần nhất, hoặc không có ván cam nào trước $i$, vậy có $f(i-k)$ cách.
- Công thức
	- Nếu $i<k$ : $f(i) = f(i-1)+1)$, vì trong đoạn $[1,k]$ chỉ có thể có 1 tấm cam.
	- Nếu $i \ge k$ : $f(i) = f(i-1) + f(i-k)$ .

## Cpp
%% Code chỉ ghi biến cần thiết ,core, không ghi full %%
```cpp


int n, k;
int mem[200005];
memset(mem, -1, sizeof(mem));
// input ...

int dp(int i) {
    if (i <= 0) {
        return 1;
    }
    if (mem[i] != -1) {
        return mem[i];
    }
    ll res;
    if (i < k) {
        res = (dp(i-1) + 1)%oo;
    } else {
        res = (dp(i-1) + dp(i-k))%oo;
    }
    return mem[i] = res;
}

cout << dp(n) << " ";
```
