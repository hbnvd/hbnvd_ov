# 01. by hbnvd - O(n!) - O(n)
## Idea
Duyệt qua tất cả nước đi, **NHƯNG** phải biết tối ưu nữa, ta sẽ vận dụng tính chất sau để tối ưu bài:
1. Thay vì ta dùng mảng 2d, ta có thể dùng mảng 1d, `i là vị trí hàng, a[i] là vị trí trên cột`
	- Nếu để ý thì mảng bây giờ sẽ là hoán vị của dãy 1...n, nên giờ chỉ cần thêm 1 mảng vis để kiểm tra xem có hậu nào lấy cột đó chưa

- Giờ chỉ còn cần kiểm tra xem 2 hậu có cùng đường chéo hay không, ta sẽ dùng 2 mảng dcc và dcp để lưu xem đường chéo phụ và chính đã đi qua chưa. Công thức tính đường chéo dựa trên vị trí hàng và cột là 
$$dcc_j=A_i + i - 1$$
$$dcp_j=n-A_i+i$$

## Cpp

```cpp
ll n, cnt;
bool vis[105], dcc[105], dcp[105];
// i = y, x = a[i]
void flying_cow(int y) {
    if (y > n) {
        ++cnt;
        return;
    }
    for (int x = 1; x <= n; ++x) {
        if (row[x] == 0 && dcc[x+y-1] == 0 && dcp[n-x+y] == 0) {

            dcc[x+y-1] = 1;
            dcp[n-x+y] = 1;
            vis[x] = 1;

            flying_cow(y+1);
            
            vis[x] = 0;
            dcc[x+y-1] = 0;
            dcp[n-x+y] = 0;
        }
    }

}

void solve() {
    memset(dcc, 0, sizeof(dcc));
    memset(dcp, 0, sizeof(dcp));
    memset(row, 0, sizeof(row));
    cnt = 0;

    cin >> n;
    flying_cow(1);
    cout << cnt << "\n";
    return;
}
```
